# Colombia 5.0 – Sitio Web Informativo Bilingüe

Proyecto académico desarrollado para el **SENA – Centro de Manufactura en Textil y Cuero**, como parte de la actividad de documentación del evento tecnológico **Colombia 5.0**.

## 🌐 Ver el sitio
[GitHub Pages Link – agregar aquí]

## 📁 Estructura del proyecto

```
colombia50/
├── index.html              ← Página de inicio
├── css/
│   └── style.css           ← Estilos del sitio
├── js/
│   └── lang.js             ← Cambio de idioma ES/EN
├── images/
│   └── img1-6.jpg          ← Fotos del evento
└── pages/
    ├── conferencias.html   ← Documentación bilingüe de conferencias
    ├── glossary.html       ← Glosario técnico (35 términos EN/ES)
    └── conclusion.html     ← Reflexión ética final
```

## 📋 Contenido

- **Inicio:** Presentación del evento, estadísticas y objetivo del sitio.
- **Conferencias:** Documentación bilingüe de dos sesiones:
  - *Game UI Systems: De Pantallas Bonitas a Interfaces que Funcionan* – Andrés Felipe Pisso Tobar (Teravision Games) ← Asignada
  - *Automatizaciones y Localización con IA* ← Libre elección
- **Glossary:** 35 términos técnicos en inglés con traducción y definición.
- **Conclusión:** Reflexión ética sobre IA, datos, automatización e impacto social.

## 🛠 Tecnologías
- HTML5
- CSS3 (Responsive, Custom Properties)
- JavaScript (Vanilla – cambio de idioma, búsqueda en glosario)

## 🚀 Despliegue en GitHub Pages
1. Sube el repositorio a GitHub.
2. Ve a **Settings → Pages**.
3. Selecciona la rama `main` y la carpeta raíz `/`.
4. El sitio estará disponible en `https://tu-usuario.github.io/colombia50/`.
