TECHNICAL GLOSSARY

Glosario

Más de 30 términos técnicos en inglés aprendidos durante el evento Colombia 5.0, con traducción al español y definición.

Mostrando 35 términos / Showing 35 terms

English Español Definition / Definición
Design SystemSistema de diseñoA collection of reusable components, guidelines, and standards that ensure visual and functional consistency across a digital product. / Colección de componentes reutilizables, guías y estándares que garantizan consistencia visual y funcional en un producto digital.
Design TokenToken de diseñoNamed variables that store visual design values such as colors, font sizes, or spacing, allowing global updates across the system. / Variables con nombre que almacenan valores de diseño visual como colores, tamaños de fuente o espaciado, permitiendo actualizaciones globales.
UI (User Interface)Interfaz de usuarioThe visual layer of a software product through which users interact with it — buttons, menus, icons, and layouts. / La capa visual de un producto de software a través de la cual los usuarios interactúan — botones, menús, íconos y disposiciones.
UX (User Experience)Experiencia de usuarioThe overall experience a person has when interacting with a product, including ease of use, efficiency, and emotional response. / La experiencia general que tiene una persona al interactuar con un producto, incluyendo facilidad de uso, eficiencia y respuesta emocional.
PrototypePrototipoAn interactive simulation of a design used to test functionality and user flows before development. / Simulación interactiva de un diseño utilizada para probar la funcionalidad y los flujos de usuario antes del desarrollo.
ComponentComponenteA self-contained, reusable building block in a design system or codebase (e.g., a button, a card, a modal). / Bloque de construcción autónomo y reutilizable en un sistema de diseño o base de código (p.ej., un botón, una tarjeta, un modal).
VariableVariableIn Figma/design, a container that stores a value (color, number, text) that can be reused and changed globally. / En Figma/diseño, contenedor que almacena un valor (color, número, texto) que puede reutilizarse y cambiarse globalmente.
Artificial Intelligence (AI)Inteligencia Artificial (IA)The simulation of human intelligence processes by machines, including learning, reasoning, and problem-solving. / Simulación de procesos de inteligencia humana por máquinas, incluyendo aprendizaje, razonamiento y resolución de problemas.
Machine LearningAprendizaje automáticoA subset of AI where systems learn from data to improve performance without being explicitly programmed. / Subconjunto de IA donde los sistemas aprenden de los datos para mejorar el rendimiento sin ser programados explícitamente.
AutomationAutomatizaciónThe use of technology to perform tasks with minimal human intervention, increasing efficiency and reducing errors. / Uso de tecnología para realizar tareas con mínima intervención humana, aumentando la eficiencia y reduciendo errores.
LLM (Large Language Model)Modelo de lenguaje grandeAn AI model trained on massive text datasets capable of understanding and generating human language. / Modelo de IA entrenado con grandes conjuntos de datos textuales, capaz de comprender y generar lenguaje humano.
AI AgentAgente de IAAn autonomous AI system that can perceive its environment, make decisions, and take actions to achieve defined goals. / Sistema de IA autónomo que puede percibir su entorno, tomar decisiones y ejecutar acciones para alcanzar metas definidas.
LocalizationLocalizaciónThe process of adapting a product for a specific language, culture, or market, beyond simple translation. / Proceso de adaptar un producto para un idioma, cultura o mercado específico, más allá de la simple traducción.
WorkflowFlujo de trabajoA sequence of tasks or processes required to complete a specific goal, often visualized as a diagram or pipeline. / Secuencia de tareas o procesos necesarios para alcanzar un objetivo, a menudo visualizada como diagrama o flujo.
API (Application Programming Interface)Interfaz de programación de aplicacionesA set of rules and protocols that allows different software applications to communicate with each other. / Conjunto de reglas y protocolos que permite que distintas aplicaciones de software se comuniquen entre sí.
Responsive DesignDiseño responsivoA web design approach that ensures interfaces adapt correctly to different screen sizes and devices. / Enfoque de diseño web que garantiza que las interfaces se adapten correctamente a distintos tamaños de pantalla y dispositivos.
FrontendFrontendThe client-side part of a web application — everything the user sees and interacts with directly in the browser. / Parte del lado del cliente de una aplicación web — todo lo que el usuario ve e interactúa directamente en el navegador.
BackendBackendThe server-side part of an application that handles data storage, logic, and communication with the frontend. / Parte del servidor de una aplicación que gestiona el almacenamiento de datos, la lógica y la comunicación con el frontend.
Cloud ComputingComputación en la nubeDelivery of computing services (servers, storage, databases, networking, software) over the internet on demand. / Entrega de servicios informáticos (servidores, almacenamiento, bases de datos, redes, software) a través de internet bajo demanda.
FigmaFigmaA collaborative, browser-based design tool widely used for UI/UX design, prototyping, and design systems. / Herramienta de diseño colaborativa basada en navegador, ampliamente usada para diseño UI/UX, prototipado y sistemas de diseño.
ScalabilityEscalabilidadThe ability of a system or design to handle increased demand or grow in complexity without losing performance or consistency. / Capacidad de un sistema o diseño para manejar mayor demanda o crecer en complejidad sin perder rendimiento o consistencia.
NLP (Natural Language Processing)Procesamiento de lenguaje naturalA field of AI focused on enabling computers to understand, interpret, and generate human language. / Campo de la IA enfocado en permitir que los computadores comprendan, interpreten y generen lenguaje humano.
Data PipelineFlujo de datosA series of data processing steps that move and transform data from one system to another. / Serie de pasos de procesamiento que mueven y transforman datos de un sistema a otro.
Version ControlControl de versionesA system that records changes to files over time, allowing teams to revert to previous versions. Git is the most common tool. / Sistema que registra cambios en archivos a lo largo del tiempo, permitiendo regresar a versiones anteriores. Git es la herramienta más común.
GitHub PagesGitHub PagesA free static site hosting service offered by GitHub, allowing developers to publish web projects directly from a repository. / Servicio gratuito de alojamiento de sitios estáticos ofrecido por GitHub, que permite publicar proyectos web directamente desde un repositorio.
RepositoryRepositorioA storage location for a project's code, managed by a version control system like Git. / Ubicación de almacenamiento para el código de un proyecto, gestionada por un sistema de control de versiones como Git.
AccessibilityAccesibilidadThe design practice of making digital products usable by people with disabilities, following standards like WCAG. / Práctica de diseño para hacer los productos digitales utilizables por personas con discapacidades, siguiendo estándares como WCAG.
Feedback (UI)Retroalimentación visualVisual or audio cues in an interface that communicate the result of a user's action, such as a button changing color on click. / Señales visuales o de audio en una interfaz que comunican el resultado de la acción de un usuario, como un botón que cambia de color al hacer clic.
Semantic ColorColor semánticoA color defined by its purpose (e.g., "Danger" = red, "Success" = green) rather than its visual value, improving design consistency. / Color definido por su propósito (p.ej., "Peligro" = rojo, "Éxito" = verde) en lugar de su valor visual, mejorando la consistencia del diseño.
TypographyTipografíaThe art and technique of arranging type to make text legible, readable, and visually appealing. / Arte y técnica de organizar el tipo para hacer el texto legible, fácil de leer y visualmente atractivo.
Spacing / Spacing ScaleEspaciado / Escala de espaciadoA defined system of consistent margins and padding values used throughout a design system for visual harmony. / Sistema definido de valores consistentes de márgenes y relleno usados en todo un sistema de diseño para armonía visual.
IterationIteraciónThe process of repeatedly refining a design or product based on testing, feedback, and new insights. / Proceso de refinar repetidamente un diseño o producto basándose en pruebas, retroalimentación y nuevos conocimientos.
DeploymentDespliegueThe process of making a software application available for use, typically by publishing it to a server or hosting platform. / Proceso de hacer disponible una aplicación de software para su uso, publicándola en un servidor o plataforma de alojamiento.
WireframeEsquema de interfazA low-fidelity visual representation of a page's layout, used in early design stages to plan structure without styling. / Representación visual de baja fidelidad de la disposición de una página, usada en las etapas iniciales de diseño para planificar la estructura sin estilos.
Ethics in TechÉtica en tecnologíaA field of study and practice concerned with the moral implications of technology development, deployment, and use on individuals and society. / Campo de estudio y práctica que aborda las implicaciones morales del desarrollo, despliegue y uso de la tecnología en individuos y sociedad.
