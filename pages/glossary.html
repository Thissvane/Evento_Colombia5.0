Technical Glossary

Más de 30 términos técnicos en inglés aprendidos durante el evento Colombia 5.0, con traducción al español y definición.

🔍

35 terms / términos

English Español Definition / Definición
Design SystemSistema de DiseñoA collection of reusable components, guided by clear standards, that can be assembled together to build applications. / Colección de componentes reutilizables guiados por estándares claros para construir aplicaciones.
Design TokenToken de DiseñoNamed entities that store visual design attributes such as colors, typography, and spacing, used to maintain consistency across a system. / Entidades con nombre que almacenan atributos de diseño visual para mantener coherencia en un sistema.
User Interface (UI)Interfaz de UsuarioThe visual layer through which a user interacts with a software product. / La capa visual a través de la cual un usuario interactúa con un producto de software.
User Experience (UX)Experiencia de UsuarioThe overall experience of a person using a product, encompassing usability, accessibility, and satisfaction. / La experiencia general de una persona al usar un producto, abarcando usabilidad, accesibilidad y satisfacción.
ComponentComponenteA reusable, self-contained UI element that can be combined with others to build interfaces. / Elemento de UI reutilizable y autónomo que se combina con otros para construir interfaces.
VariantVarianteA different version of a component that reflects a specific state or style, such as primary, secondary, or disabled. / Versión diferente de un componente que refleja un estado o estilo específico.
Auto-layoutAuto-disposiciónA Figma feature that automatically arranges child elements within a frame, adapting to content changes. / Función de Figma que dispone automáticamente los elementos hijos dentro de un marco.
Color PalettePaleta de ColoresA defined set of colors used consistently throughout a design system or product. / Conjunto definido de colores usados de manera consistente en un sistema de diseño o producto.
Typography ScaleEscala TipográficaA systematic set of font sizes and weights that define visual hierarchy in a design. / Conjunto sistemático de tamaños y pesos de fuente que define la jerarquía visual.
HUD (Heads-Up Display)Pantalla de información superpuestaIn gaming, the visual layer displayed on screen that shows game information like health, score, and map. / En videojuegos, la capa visual que muestra información como salud, puntaje y mapa.
LocalizationLocalizaciónThe process of adapting a product to a specific locale, including language, culture, and regional formats. / Proceso de adaptar un producto a un idioma, cultura y formato regional específicos.
Internationalization (i18n)InternacionalizaciónThe design process of making a product ready for adaptation to multiple languages and regions without re-engineering. / Proceso de diseño para preparar un producto para múltiples idiomas y regiones sin rediseñar.
Machine TranslationTraducción AutomáticaThe use of software and AI to automatically translate text from one language to another. / Uso de software e IA para traducir automáticamente texto de un idioma a otro.
Translation MemoryMemoria de TraducciónA database that stores previously translated text segments to ensure consistency and speed up future translations. / Base de datos que almacena segmentos de texto traducidos previamente para garantizar consistencia.
Consistent TermsTérminos ConsistentesWords or phrases that must remain identical throughout an application, such as brand names or specific commands. / Palabras o frases que deben mantenerse idénticas en toda la aplicación.
Artificial Intelligence (AI)Inteligencia Artificial (IA)The simulation of human intelligence processes by computer systems, including learning, reasoning, and self-correction. / Simulación de procesos de inteligencia humana por sistemas computarizados.
AutomationAutomatizaciónThe use of technology to perform tasks with minimal human intervention, increasing efficiency and consistency. / Uso de tecnología para realizar tareas con mínima intervención humana.
WireframeEsquema de páginaA low-fidelity visual representation of a UI layout, focusing on structure rather than visual design. / Representación visual de baja fidelidad de un diseño de UI, centrada en la estructura.
PrototypePrototipoAn interactive simulation of a product used to test and validate design decisions before development. / Simulación interactiva de un producto usada para probar y validar decisiones de diseño antes del desarrollo.
Responsive DesignDiseño ResponsivoAn approach to web design that makes web pages render well on a variety of devices and window or screen sizes. / Enfoque de diseño web que hace que las páginas se vean bien en diferentes dispositivos y tamaños de pantalla.
Accessibility (a11y)AccesibilidadThe design practice of making products usable by people with disabilities, including visual, auditory, motor, or cognitive impairments. / Práctica de diseño para hacer productos utilizables por personas con discapacidades.
Cloud ComputingComputación en la NubeThe delivery of computing services including servers, storage, databases, networking, and software over the internet. / Entrega de servicios de computación como servidores, almacenamiento y software a través de internet.
API (Application Programming Interface)Interfaz de Programación de AplicacionesA set of rules that allows different software applications to communicate with each other. / Conjunto de reglas que permite que diferentes aplicaciones de software se comuniquen entre sí.
FrontendInterfaz de cara al usuarioThe part of a web application that users interact with directly, built with HTML, CSS, and JavaScript. / Parte de una aplicación web con la que los usuarios interactúan directamente.
BackendParte del servidorThe server-side of a web application that handles business logic, databases, and application functionality. / Lado del servidor de una aplicación web que maneja lógica de negocio y bases de datos.
Version ControlControl de versionesA system that records changes to files over time so specific versions can be recalled later. / Sistema que registra cambios en archivos a lo largo del tiempo para poder recuperar versiones específicas.
RepositoryRepositorioA storage location for software packages, often managed with version control systems like Git. / Ubicación de almacenamiento para paquetes de software, generalmente gestionada con sistemas de control de versiones.
FrameworkMarco de trabajoA pre-written code library that provides a structure and set of tools to help developers build applications more efficiently. / Biblioteca de código preescrita que proporciona estructura y herramientas para construir aplicaciones de manera eficiente.
User ResearchInvestigación de usuariosThe systematic study of target users to understand their behaviors, needs, and motivations to improve product design. / Estudio sistemático de usuarios objetivo para entender comportamientos, necesidades y motivaciones.
UsabilityUsabilidadThe ease with which users can use a product to achieve their goals effectively, efficiently, and satisfactorily. / Facilidad con la que los usuarios pueden usar un producto para lograr sus objetivos de manera efectiva.
IterationIteraciónThe repetition of a process where each cycle builds upon the results of the previous one to continuously improve a product. / Repetición de un proceso donde cada ciclo se basa en los resultados del anterior para mejorar continuamente.
Natural Language Processing (NLP)Procesamiento del Lenguaje NaturalA branch of AI that helps computers understand, interpret, and generate human language. / Rama de la IA que ayuda a las computadoras a entender, interpretar y generar lenguaje humano.
ScalabilityEscalabilidadThe ability of a system to handle increased workload or demand without compromising performance. / Capacidad de un sistema para manejar mayor carga de trabajo sin comprometer el rendimiento.
AgileÁgilA project management and software development approach that encourages flexible, iterative work and collaboration. / Enfoque de gestión de proyectos y desarrollo de software que fomenta el trabajo flexible e iterativo.
Data EthicsÉtica de datosThe branch of ethics that evaluates data practices to ensure they align with moral principles, particularly regarding privacy, consent, and fairness. / Rama de la ética que evalúa prácticas de datos para garantizar su alineación con principios morales.
